  • Group-Object | group
    • Recap: it counts the number of same value you group of a property, useful for csv.
    • Run: 
      $portPoints | group port
# complex.
Get-ChildItem -File |
Sort-Object Extension |
  Group-Object -NoElement -Property @{
    Expression={
      switch ($_.Extension) {
        '.md'   {'Content'}
        ''      {'Metacontent'}
        '.ps1'  {'Automation'}
        '.yml'  {'Automation'}
        default {'Configuration'}
      }
    }
  }
    • Resolution:
      • Use this extensively for counting occurence of a value of a property, in a JSON object or an array, or an hashtable of very big things.
