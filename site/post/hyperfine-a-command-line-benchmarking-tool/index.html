  • hyperfine: A command-line benchmarking tool
    • Recap:
    • Resolution: dont try to run benchmarking binaries with cmdlets in pwsh. Shell startup time is 1min. 
      hyperfine -S=pwsh "eza" "gci" --show-output  
hyperfine -Spwsh "eza" -L list_function gci ls "{list_function}"
# Or faster, run this.
hyperfine --runs 2 "eza -T" "tree"
      • --show-output self-explained.
      • --parameter-scan | -P will Parameterized benchmarks with numeral inputs
        • use with --parameter-step-size | -D will lerp the range of two numbers.
        • --parameter-list | -L will be used for strings.
      • --runs specify exact amount of times running.
    • Reason:
      • Pro: compare function within my shell vs dedicated program in $PATH or relative to $pwd.
      • Cons: super slow, it's calibrating for shell startup time as well...
        • To run without intermediate shell -N need to be added.
    • Root: I'm still looking for a way to diff command output without saving them to files.
