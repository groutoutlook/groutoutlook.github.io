  • How can I find the short path of a Windows directory/file?
    • Recap: short path with no space, for example PROGRA~1. Use cmd /c dir /x
    • Run: for #powershell 
      (New-Object -ComObject Scripting.FileSystemObject).GetFolder("$pwd").ShortPath
# To get short path of some item.
gci|%{(New-Object -ComObject Scripting.FileSystemObject).GetFolder("$_").ShortPath}
    • Reason: sometimes you want this for consistent path in #scripting
    • Root: old DOS convention.
