  • Since I frequently test my shaders in WT, better way to distribute computing powers is use GPU 1 (NVDIA) to execute Shader code.
  • While GPU0 is still the main Display code. GPU 1 could be used using Windows Settings -> System -> Display -> Graphic -> Search for programs there.
    • If the apps are packaged type, there are also options to Add Desktop App or Add Microsoft Store App
