  • ouch Painless compression and decompression in the terminal
    • Recap: #nightly yeah. I shim it to zip.
    • Run: so useful for case that you want to quickly peek into compressed files. 
      ouch l .\any.zip -t # tree like render to terminal. list items in archives..
ouch c ./$source ./$dest.zip
(f -td) |%{$_-replace'\\'}|%{ouch c $_ "$_.zip"} # a bit more advance could be using ouch with `fd`
gci |%{ouch d $_} # much faster than Explorer's `Extract All...` (T2)
    • Resolution: ouch correctly display unicode name of certain things, unlike tar tf
      • ouch avoid much edge case that Compress-Archive stuck at e.g. [].png bracket in the end of name kind of stuck... Unicode, much more.
