  • regex
  • Do not use ""(double quotes) to contain regex patterns.
    • Reason: PowerShell requires an extra backtick "`" to distinct those regex character.
      • Especially square bracket [] and parentheses ().
    • Resolution: Use ''(single quotes) in any case.
