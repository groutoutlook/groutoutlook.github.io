      • Recite: access my Github Copilot API key. GitHub Copilot not provide an (public) API key for individual or enterprise users.
        • You can’t programmatically access Copilot’s code suggestions via an API.
        • GitHub Copilot works only through IDEs (like VS Code, JetBrains, or Neovim), where it integrates directly via your GitHub account and license.
        • There’s no separate API key issued for using Copilot like an OpenAI or Hugging Face API.
