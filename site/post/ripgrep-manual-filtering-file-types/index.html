rg --type-add 'web:*.html' --type-add 'web:*.css' --type-add 'web:*.js' -tweb title
      • --type-add flag only applies to the current command. It does not add a new file type and save it somewhere in a persistent form. If you want a type to be available in every ripgrep command, create alias or add --type-add=web:*.{html,css,js} to your ripgrep #config file.
