  • To output from pwsh my commonly used date time format:
    • Recap:
    • Run: 
      Get-Date -Format 'yyyy-MM-dd hh:mm:ss tt'
date -uf '%F %r'
    • Resolution:
      • To reformat existed date and time, only biff can be used.
        • Run:
        biff time fmt -f '%c' '2025-03-09T02:30[America/New_York]'
        • Related: A bit #trivia from the doc itself:
          • Find the last Saturday every other month, starting with the current month, for the next year. And format the datetime in your locale:
          # $env:BIFF_LOCALE='en-US'
biff time seq monthly today -i2 -w -1-sat --until 1y | biff time fmt -f '%c'
# Print all Friday the 13th occurrences for the next 3 years
biff time seq monthly today --until 5y -w fri -d 13
