  • Quick snippet for making a sheet of firmware quantity in the fly. Plus hash.
    • Recap: given you already include the quantity on the first in file name.
    • Run: 
      '3000pcs-fw1-C6U-25-BiggerGap (2).hex','.\1000pcs-0m5.hex','.\500pcs-0m7.hex','.\500pcs-0m9.hex' |
ForEach-Object {
    $hash = Get-FileHash $_
    [pscustomobject]@{
        algo     = $hash.Algorithm
        hash     = $hash.Hash
        quantity = ($hash.Path -replace '.*?(\d+)pcs.*', '$1')
        file     = [System.IO.Path]::GetFileName($hash.Path)
    }
} | ConvertTo-Csv -NoTypeInformation > ./25-11-25-Firmware-quantity.csv
