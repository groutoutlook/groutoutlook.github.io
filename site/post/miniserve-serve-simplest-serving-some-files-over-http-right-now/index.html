    • Run:

      • Recite:
      miniserve linux-distro-collection/ ### Serve a directory:
miniserve linux-distro.iso ### Serve a single file:
miniserve --index test.html ### Set a custom index file to serve instead of a file listing:
miniserve --spa --index index.html ### serve SPA so non-existent paths are forwarded to SPA's router instead
miniserve --auth joe:123 unreleased-linux-distros/ ### Require username/password:
### Require username/password as hash:
pw=$(echo -n "123" | sha256sum | cut -f 1 -d ' ')
miniserve --auth joe:sha256:$pw unreleased-linux-distros/
miniserve --auth-file auth.txt unreleased-linux-distros/ ### Require username/password from file (separate logins with new lines):

miniserve -i 192.168.0.1 --random-route /tmp ### Generate random 6-hexdigit URL: /private/tmp at http://192.168.0.1/c789b6
miniserve -i 192.168.0.1 -i 10.13.37.10 -i ::1 /tmp/ ### Bind to multiple interfaces

miniserve -u -- . # in host
curl -F "path=@$FILE" http://localhost:8080/upload\?path\=/ # client upload using curl

miniserve -u -m image -q ### Take pictures and upload them from smartphones
# this uses the `--media-type` option, which sends a hint for the expected media type to the browser.

      Note that for uploading, we have to use -- to disambiguate the argument to -u. This is because -u can also take a path (or multiple). If a path argument to -u is given, uploading will only be possible to the provided paths, not every path.

      Another effect of this is that you can't just combine flags like this -uv when -u is used. In this example, you'd need to use -u -v.
