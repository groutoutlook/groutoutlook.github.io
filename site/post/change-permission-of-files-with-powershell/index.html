    • Run: in this case AWS complaining ssh keys permission is too opened. 
      New-Variable -Name Key -Value "$env:UserProfile\.ssh\id_rsa" # Set Key File Variable:

Icacls $Key /c /t /Inheritance:d # Remove Inheritance:

Icacls $Key /c /t /Grant ${env:UserName}:F # Set Ownership to Owner:  Key's within $env:UserProfile:

TakeOwn /F $Key # Key's outside of $env:UserProfile:
Icacls $Key /c /t /Grant:r ${env:UserName}:F

Icacls $Key /c /t /Remove:g Administrator "Authenticated Users" BUILTIN\Administrators BUILTIN Everyone System Users # Remove All Users, except for Owner:

Icacls $Key # Verify:

Remove-Variable -Name Key # Remove Variable:
