  • comrak: CommonMark + GFM compatible Markdown parser and renderer
    • Recap: convert from a markdown file with the path into HTML in the stdout.
      • really similar to a SSG.
    • Run: 
      comrak $jtb["fm"] | b -lhtml # for my profiles... could try a readme for a simpler example.
# A variable can contain a file handle. with `miniserve` you can update the file....
# with text editor even.
comrak $jtb["fm"] > ($a = ni -p $env:TEMP -n "edgerun.html" -Force); miniserve $a && rm $a
# hopefully in the future it could be like this.
comrak $jtb["fm"] > ($a = New-TemporaryFile -extension html); msedge $a
      • #cli/option : -o | --output "FILE" will output to a file, thus reduce above kludges. 
        comrak ./README.MD -o ./README.html ; msedge $pwd/README.html # notice msedge cant expand the "." dir.
