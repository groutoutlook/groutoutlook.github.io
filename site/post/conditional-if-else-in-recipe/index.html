  • conditional if/else in recipe
    • Recap: only for variables.
    • Run: 
      foo := if "hello" =~ 'hello' { "match" } else { "mismatch" }
      • != operator in justfile do exact match comparison, matching regex we use =~.
    • Resolution: you can put variable inside of them. no closure.
      • or even output from backtick expression: 
        bar := "this is bar."
foo := if env_var("release") == "true" { `get-something-from-release-database` } else { bar }
    • Reason:
    • Root: setting variable inside recipes
    • Related:
      • you can write them multiline inside recipe, lifetime is of course limited within recipe.
