    • Run: mostly I use with sudo.

sudo run pwsh -file ./aScriptThatSudo.ps1
pwsh -cwa "echo yeah" -c "echo no" # CommandWithArgs superseded Command

      • -File | -f flags
        • Most command situation you ever need to launch pwsh.exe cli.
      • -ConfigurationFile Specifies a session configuration (.pssc) file path.
      • -EncodedCommand | -e | -ec same as -c but accept Base64-encoded string version.
        • Recap: submit commands to PowerShell that require complex, nested quoting.
        • Related: decode a Base64 string?
          • Run: 
            [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes('Motörhead'))
[Text.Encoding]::Utf8.GetString([Convert]::FromBase64String('TW90w7ZyaGVhZA=='))
          • Rival: unmaintained but TextUtility Microsoft.PowerShell.TextUtility module
      • -NoProfile | -nop self-explained.
        • Useful when you abruptly corrupt your $Profile beyond repair. Or use with -file.
        • #runner : within justfile. It's my default template. Rarely I prefer it having some modules.
      • -SSHServerMode | -sshs for using within sshd_config.
        • #windows: Speaking of which, change default sshd_config by Invoke-SudoPwsh "hx $env:ProgramData\ssh\sshd_config"
