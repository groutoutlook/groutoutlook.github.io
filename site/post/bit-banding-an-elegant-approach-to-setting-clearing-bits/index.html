  • Bit-banding – An Elegant Approach to Setting & Clearing Bits
    • Recap: almost every M3/M4 chip have this bit band alias region.
    • Run: alias each bit in a register to a whole byte. so you can loop and read/write to each bit. No Read Modify Write.
      • doesn't have a benefit when you are writing GPIOB->ODR = 0x00000002 or GPIOB->BSRR = 0x00000002 since those are already atomic.
