  • nuitka Python compiler written in Python
    • Recap: compile scripts into a single executable to shim to PATH as common tools. E.g: ninjatracing
    • Run:
      • method 1: venv
      uv venv
.\.venv\scripts\activate
uv pip install nuitka
python -m nuitka --onefile --standalone ./ninjatracing.py
      • method 2: direct add
      uv add --dev nuitka # if you havent added it to `uv.lock`, otherwise  `uv run`
uv run python -m nuitka --standalone ./ninjatracing.py
