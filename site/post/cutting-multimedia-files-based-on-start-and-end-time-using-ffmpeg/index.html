  • Cutting multimedia files based on start and end time using ffmpeg
    • Recap: ffmpeg cut videos pretty easy. Can have millisecond resolution.
    • Run: -to is length of result videos. -end is referring to the timestamp in the original video. 
      ffmpeg -ss 00:00:10.7 -to 00:02:42 -i .\Magnetic-choreo.webm  -c copy .\Magnetic.webm # quick but not precise.
ffmpeg -ss 49.678 -to 04:13.678 -i .\sb19-dam-backup.webm  .\sb19-dam.webm # precise but slow.
ffmpeg  -i .\Lemonade-Aespa.webm  -ss 0 -to 03:07.6 -c copy .\Lemonade-Aespa.mkv -y # overwrite, position can be whatever.
      • this goes both way. Actually I found -to better than end somehow...
      ffmpeg -ss 00:00:00.52 -i .\puppetShow-xg.webm -ss 00:00:00 -i '.\06 - PUPPET SHOW.flac'   -map 0:v -map 1:a -c:v copy -c:a flac -shortest .\puppetShow-xg.mkv
    • Resolution: if you specify wrong -to or -end duration, it will start at the wrong time.
