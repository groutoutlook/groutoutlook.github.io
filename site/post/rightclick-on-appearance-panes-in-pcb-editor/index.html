Hide All Non Copper Layers Ctrl+Alt+5
Show All Layers Ctrl+Alt+6

Show Only Front Assembly Layers Ctrl+Alt+8
Show Only Front Layers Ctrl+Alt+9
Show Only Back Layers Ctrl+Alt+0
