  • Quickly render structure of a directory to both svg and png.
    • Recap:
    • Run: auto resizing since the stdout can be arbitrarily long. 
      tree --color=always *>&1 | termframe -Wauto -Hauto > tree-l1.svg && msedge file://$pwd/tree-l1.svg && resvg ./tree-l1.svg ./tree-l1.png && catimg ./tree-l1.png
# or when you want to render color on a code snippet.
gcb | b -lc --no-pager --color=always| termframe -Wauto -Hauto > RenderedCode.svg && msedge file://$pwd/RenderedCode.svg && resvg ./RenderedCode.svg ./RenderedCode.png && catimg ./RenderedCode.png
