    • Recap: imagine default type T, now with std::nullopt state. This is nullable type.
    • Run:
    • Resolution:
      • used as a RTTI feature, which can convert between type safely without punning.
        • E.g. for serializing need.
        • See: Wrappers for custom writing for types
          • if you want to write bools as numbers and some quoted numbers for examples.
      • when uninitialize, it's discoupled(nullopt state).
        • A common use case for optional is the return value of a function that may fail.
