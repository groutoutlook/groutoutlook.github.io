  • pass arguments to dependency
    • Recap: build: (conf "args here")
    • Root: trying to call a recipe with arguments to dependency.
    • Resolution: after recipe name, the construct word behind it would be
      • dependency: after colon e.g : build: conf
      • arguments : before colon as : build *flags:
        • it can have a default value as recipe_name arg=declared_var arg2="string"
        • the sequence is dependencies then arguments..
        • default values may be arbitrary expressions, but which have +, &&, ||, / operators must be parenthesized.
          • those are builtin operator
        • last parameter may be variadic, start with + or * before the argument name.
          • which is normally recipe +files: do_something {{files}}.
            • + 1 or more args.
            • * 0 or more args, default to empty string, variadic parameter for just
              • one usage is specify flags/options into just's recipes invocation.
