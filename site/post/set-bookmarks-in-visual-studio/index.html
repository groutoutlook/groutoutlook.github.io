keybinding action
Ctrl+k ctrl+k create or toggle bookmark
Ctrl+k ctrl+f create new folder
Ctrl+k ctrl+p move to prev bookmark
Ctrl+k ctrl+n move to next bookmark
Ctrl+shift+k ctrl+shift+p move to prev bookmark in folder
Ctrl+shift+k ctrl+shift+n move to next bookmark in folder
... disable or enable all bookmarks
... delete bookmark/folder
