  • To check all the features in a crate by cargo
    • Recap:
    • Run: 
      cargo read-manifest | fx
cargo metadata --format-cargo metadata --format-version 1 | fx 'x => x.packages.find(p => p.name === "biff-datetime-cli").features' Object.keysversion 1 | yq '.packages[] | select(.name=="THE_CRATE_NAME_HERE") | .features | keys[]'
# then 
cargo build --features locale #or straight up using all: cargo build --release --workspace --all-features
