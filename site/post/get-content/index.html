  • Get-Content
    • Recap: Get the content of an alternate data stream
    • Run: 
      Get-Content main.log -Wait
    • Resolution:
      • gc -Wait flag
        • check once per second(1s cycle).
      • -TotalCount flag
        • Regimen: -Wait with a specific number of lines. Convenient.
      • -ReadCount flag
        • Regimen: specify amount of lines to pipelines output.
        • Run: gc .\MainJournal.md -ReadCount 3 |%{ $_.Length}
      • -Stream flag
      • Get raw content
      • -AsByteStream && -Raw to get file contents as a byte array
        • To count how many bytes to it, or to read things as system compiled lang do(C++, Rust,...)
          • quite useful e.g. glaze errors can only spit out the position of which token it felt like errors. using Get-content -AsByteStream -Raw to get [byte[]] array. then use hx to navigate to that exact char by 900l or something.
      • custom get-content -Delimiter
        • not very important
