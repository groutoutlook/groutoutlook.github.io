    • Root:
    • Resolution:
      • Cursors will collide with next one if you move them.
        • So to spawn new one, dont hesitate to C. You can always
          • , to collapse to the latest spawn one. No cursor left.
          • Alt+, to despawn the latest one.
          • go to end of file and collapse them manually by moving.
          • press x will match to the end of line. you can enter select mode - s...
            • to select wanted characters to spawn cursors in.
        • x/X will extend to end of line without entering select mode, which can avoid some havocs
          • like accidentally insert or change or replace. Those fucked me up a lot.
      • When enter select mode, dont try too hard to match new text objects.
        • You could enter insert mode first.
        • if you're in select mode/visual mode, press v to go to normal mode again.
          • Esc will collapse all the cursors, which is bad.
        • v$ / vgl select to end of line.
        • vgw will select to words, which is even more brilliant.
        • vs<query><prefix>n immediately spawn prefix number of cursors on next match.
          • which is insanely faster than navigate around honestly.
          • You have to remember to quit visual mode on the end by pressing v after done matching.
          • Do some quick navigation like vt<query> or vf<query>.
          • collapse_selection, Sometimes you may forgot that and seeing the highlighting trail.
