      • to make a pull request on other repo: 
        gh repo clone gwsw/less # or `gh ro`.

git sw -c "semantic/commit"

gh pr create # or `gh pcamt`. There is `gh pct "title here as well"`
gh pv # show on pager. Kinda cool. It will show your current working pull request.
gh pr view --web # or `gh pvw`

      gh pr merge -d 1 # or gh pm -d 1

      if dont want to merge.

      gh pr close -d 1 # or gh po -d 1 after all done.

      - workflow is mainly open an issue with `gh issue create` | `gh ic` then `gh pc`.
  - [linking a pull request to an issue - github docs](https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/linking-a-pull-request-to-an-issue)
  - create branch, commit and `gh pc -t "chore: fix something" -b "fix #6"`. special keyword syntax there.
