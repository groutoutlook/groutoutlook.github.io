  • Swap/Merge high quality audio tracks using ffmpeg. Using #AI to retrieve those flags.
    • Recap:
    • Run: 
      mpv .\likethat-babymon-8k.webm --audio-file=.\03-babymonster-like_that.flac
ffmpeg -i .\likethat-babymon-8k.webm -i .\03-babymonster-like_that.flac -filter_complex "[1:a]adelay=2600|2600[a]" -map 0:v -map "[a]" -c:v copy -c:a libopus .\likethat-babymon-8k-dub-flac.webm
ffmpeg -i .\Magnetic.webm -ss 00:00:07.3 -i '.\02. ILLit - Magnetic.flac' -map 0:v -map 1:a -c:v copy -c:a flac -shortest Magnetic.mkv # the only way to retain flac is mkv, not av1-webm pair.
# it can even be arbitrary like this. notice the order of ss.
ffmpeg -ss 158.007 -i psycho-babymonster.webm -i "BABYMONSTER - WE GO UP - 02 PSYCHO.flac" -map 0:v -map 1:a -c:v copy -c:a copy -shortest psycho-babymonster-part2.mkv
