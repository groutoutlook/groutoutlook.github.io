  • docker exec is a huge pain.
    • Recap:
    • Root:
    • Resolution: Find existed runningID of running images. 
      $runningID = (docker ps --format "{{json .}}" | ConvertFrom-Json)[0].ID    
docker exec -i $runningID  bash -c "find /bin/m*"
    • Reason: For piping files from host machine to running images, we have to do that roundabout. 
      cat .\my_example.cpp | docker exec -i $runningID sh -c "cat > /my_example.cpp"
