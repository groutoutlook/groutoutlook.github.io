    • Run: 
      &{
Write-Warning "hello`n"
Write-Error "hello`n"
Write-Output "hi"
} 3>&1 2>&1 > ~\redirection.log
2>&1 # Redirects the specified stream(here is Error) to the Success stream.
*>&1 # Write-* come to stdout/Success stream
    • Resolution: about_Redirection

      • Type of stream:

        Stream # Description Write Cmdlet

        5 Debug Stream Write-Debug
        6 Information Stream Write-Information, Write-Host
        * All Streams

      • Redirection operators: >(Send),>>(Append),>&[1..6](redirect to [1..6])
