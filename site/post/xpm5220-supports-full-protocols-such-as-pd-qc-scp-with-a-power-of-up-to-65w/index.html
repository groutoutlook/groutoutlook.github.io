    • Recap: the most clear CC CV PSU explaination is in here.
      • Recite: When the output current is less than the set value, the output CV mode is constant; When the output current is greater than the set value, the output CC mode is output, and the output voltage decreases. The output voltage of the XPM5220 has a wire compensation function, and the output voltage will be increased accordingly when the output current increases to compensate for the voltage drop caused by the impedance of the connecting wire.
