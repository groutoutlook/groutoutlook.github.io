    revoke.py: Anti-recall silent
changes all revokemsg recall operation messages to unknown messages, which cannot be successfully recalled and there is no recall prompt.

unmutex.py: Multi-open
and remove 4.0.3+ Mutex detection, you can start the same WeChat program multiple times. It is not recommended to log in to multiple accounts, and it is easy to crash.

coexist.py: Coexistence Edition Maker
selects the number ζ=0~9 to create a coexistence version Weixin.exe (up to ten), isolation settings, and automatic login ports.
All message records in the coexistence version are shared with the original version, and you can log in at will.

sound_extract.py: Extract the prompt
to extract the prompt to the current directory, the file name is .Sound_编号_十六进制大小.wav

sound_replace.py: Modify the prompt to
replace the prompt, the new audio must be in WAV format, and the size cannot exceed the original (if it is exceeded, it will be truncated).
