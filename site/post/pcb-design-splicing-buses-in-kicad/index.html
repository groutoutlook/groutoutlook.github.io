    • Resolution: In eeschema Inspect (alt+i) -> Show Bus Syntax Help will show all this.
      • #keybinding default is b, from Buses
      • Vector bus is a collection of signals that start with a common prefix and end with a number.
        • Run: PB[0..15], USB[0..1]_W[..] or so.
      • Group bus is a collection of one or more signals and/or vector buses.
        • Run: Group have more explicit syntax with curly brace as the grouping e.g. I2C0_{SCL SDA}
          • Space in signal name is \ (not \s as I imagine).
      • #keybinding c == Unfold from Bus but first selected bus. It's global, can invoke anywhere you want.
