  • Key used within picker e.g. jumplist or file picker, most used should be Ctrl+s or Ctrl+v since it is splitting.
    • Recap:
    • Run:
    • Resolution: space f open file picker from git repo directory.
      • space F open file picker from current invocation directory i.e open hx in nested dir.
      • Remember :pwd to check current working directory and :cd to change it.
        • File picker worked based on that.
      • Pickers filtering syntax
        • it's similar to how fzf match, which is there are spaces to separated words.
        • Recite:
          • If a picker shows multiple columns, you may apply the filter to specific column by adding the column name with %. Column names can be shortened to any prefix, so %p, %pa or %pat all mean the same as %path.
          • helix %p .toml !lang in the global search picker search term "helix" within files with paths ending in ".toml" but not including "lang".

Keybinding Action
Shift-Tab, Up, Ctrl+p Previous entry
Tab, Down, Ctrl+n Next entry
PageUp, Ctrl+u Page up
PageDown, Ctrl+d Page down
Home Go to first entry
End Go to last entry
Enter Open selected
Alt+Enter Open selected in the background without closing the picker
Ctrl+s Open split horizontally
Ctrl+v Open split vertically
Ctrl+t Toggle preview
Escape, Ctrl+c Close picker
