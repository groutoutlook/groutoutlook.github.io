  • microcontroller - Circuit to switch power between Battery and main Source for BLE Module
    • Recap: crittical if you want hybrid BLE capable MCU + RTC with VBAT connect to button cell as CR2032
    • Run: may have to use ST17H66B2 now, due to its characteristic with deep sleep
      • with 1ua Sleep mode, 32 Khz RTC ; 4uA if you keep RAM.
    • Resolution: power selection circuitry as LTC4412.
      • Seamless Switchover for Backup Power Reference Design - tidue50.pdf
      • Selecting the correct IC for power-supply applications - slyt259.pdf
    • Reason:
      • Con: ST17 internal 32KHz RC OSC is super low accuracy at 500ppm error. normal RTC are 3-5ppm.
      • Pro: you can slap primary/backup power chip on just this one alone. no RTC module/chip need, yet.
        • you can leave spare pin to add RTC later for enhanced accuracy.. which mean you dont need I2C for now.
        • currently 280pcs of that board, draw a power selection/switch board instead to boot up a MVP..
    • Root: good idea to use the internal RTC of a microcontroller or is it better to use an external one?
