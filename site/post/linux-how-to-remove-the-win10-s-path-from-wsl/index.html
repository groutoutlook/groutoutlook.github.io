  • linux - How to remove the Win10's PATH from WSL
    • Recap:
    • Run: Append this on /etc/wsl.conf 
      [interop]
appendWindowsPath = false
    • Resolution:
      • #doc/official : Advanced settings configuration in WSL wsl.conf is per distro config. .wslconfig is global one.
        • to make it clear, /etc/wsl.conf is not in $HOME or $env:Appdatadirectory
    • Reason:
      • Pro: cleaner env
      • Con: cant call e.g. hx.exe or jrnl.exe from within wsl.
