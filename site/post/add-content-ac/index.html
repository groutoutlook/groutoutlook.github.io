  • Add-Content | ac
    • Recap: for adding content, even to the opened/locked files. Useful when logging.
    • Run: 
      Add-Content main.log "INFO:  screaming"
    • Resolution: Add content to a read-only file with -Force
    • Reason:
    • Root: e.g: using with watchexec for Get-Content main.log -Wait or ov --watch 1.
