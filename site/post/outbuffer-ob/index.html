  • -OutBuffer| -ob
    • Recap: use with foreach|% and where, normally a ScriptBlock, not standalone cmdlet
    • Run: usage with %, alternates in batches of 2 or OutBuffer + 1. 
      1..4 | ForEach-Object {
    Write-Host "$($_): First"; write ($_*5)
  } -ob 1 -ov b | ForEach-Object {}{Write-Host "$($_): Second" } {echo "$b is weird"}
      • Require the code block to accumulate a number of value instead of sending instantly.
      • If elements are exhausted, it will flush i.e. process anything left in the buffer.
    • Resolution: also see write -n for passing a whole array.
      • #note : IMPORTANT this doesnt meant $_ being promoted into list or array type.
        • it just delay them a several iterating cycle.
        • For that usage check Suggestion: Add a chunking (partitioning, batching) mechanism to Select-Object, analogous to Get-Content -ReadCount · Issue #8270 · PowerShell/PowerShell
