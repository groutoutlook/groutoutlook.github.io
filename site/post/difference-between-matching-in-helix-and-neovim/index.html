  • difference between matching in helix and neovim
    • Recap: miw, mi" will match/select them first before changing/deleting anything.
    • In neovim, we can ciw to change, diw to delete,...
  • Helix have a different matching scheme... outside of bracket/quote, it will not match the one which is in the current line like neovim do.
    • Instead it match what's between.
