  • Select-Object | select
    • Recap: use with sort -pr.
    • Run: 
      scoop l | select source -Unique
    • Resolution:
      • -First/Last take a slice from start/last.
      • -Index take only one entry at index
      • -Skip/-SkipLast skip a slice. Unlike the Index parameter, which starts counting at 0, the Skip parameter begins at 1.
      • -SkipIndex skip a certain index, convenient in case it's in the middle of the list.
