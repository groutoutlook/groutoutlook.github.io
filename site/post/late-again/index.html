    • Resolution:
      • All meetings should start at a time ending in 5 on the minutes side. e.g. 10:35 is a valid start time.
      • All meetings should end at a time ending in 0 minutes. e.g. 10:30 is a valid end time.
      • Everyone needs some time for composure (travel time, bathroom, drinks etc.),
      • sometimes you have to run the last meeting a few mins over.
      • By starting on the *5 and setting that as the start time on the calendar you give yourself this time.
      • This is especially true at senior levels where you have strings of back to back meetings.
      • The expectation is then set.
      • You show up at 10:35 precisely and no one’s waiting 5 mins.
