  • weixin screenshot by win+shift+f1 since that one can help me highlight things.
    • Recap: quite useful for what its worth.
    • Run: but if you really want to do win+shift+s, enable/disable through powershell. 
      New-ItemProperty -Path "HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced" -Name "DisabledHotkeys" -PropertyType String -Value "S" -Force
Stop-Process -Name explorer -Force
# Re-enable default `win+shift+s` screenshot of windows.
Remove-ItemProperty -Path "HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced" -Name "DisabledHotkeys" -ErrorAction SilentlyContinue
Stop-Process -Name explorer -Force
    • Resolution: this will disable Windows's screenshot and over-relying on Wechat so... either you enable it all the times or use ScreenCapture for it.
