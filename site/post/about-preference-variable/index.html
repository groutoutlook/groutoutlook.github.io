      • $OFS - PowerShell
        • Use for the stringify of primitive array type like [array] and others.
        • Recite: separate the values when an array is converted to a string.
        • Run: 
          $OFS = "+";[string](1,2,3,4); # output 1+2+3+4. alternative is `-join` or `-f`.
        • It's something really similar to IFS and FS in grep/awk/bash.
