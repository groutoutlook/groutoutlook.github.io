  • probe-rs's cli is not very good at detecting which probe is connect to which.
    • Recap: have to use pyocd as well. Shim #nightly to pro for ease of typing.
    • Run: 2 liner which directly iterate through every probe. 
      $text=(pro list);[string[]]$pr = (sls -InputObject $text -Pattern '(?<=--\s)[0-9A-Fa-f]{4}:[0-9A-Fa-f]{4}:[^\s)]+' -AllMatches).Matches|% { $_.Value }; $pr
$pr | % { Write-Warning "$_ finding..."; pyocd cmd -u (($_ -split ':')[-1]) -c reset }
