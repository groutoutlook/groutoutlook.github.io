  • want to find llvm or clang using cmake, you have to build llvm locally, one way or another.
    • Recap: and if possible, assign $env:clang_dir;$env:llvm_dir.
    • Resolution: you can build with ninja and cmake. 
      cd llvm-project
md build
cd build
set cc cl
set cxx cl
cmake -gninja -dllvm_enable_projects=clang ..\llvm
ninja clang
ninja clangtooling # ffs...
ninja checK-clang # optional
