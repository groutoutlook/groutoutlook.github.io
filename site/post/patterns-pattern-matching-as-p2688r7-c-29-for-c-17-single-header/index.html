  • patterns pattern matching as P2688R7(C++29) for c++17, single header
    • Recap:
    • Run: match(expression)(pattern(<pattern>) = <lambda>,...);
      • Expression Pattern: matching some condition range, or null or placeholders, in the style of case as tuples.
      • Arg Pattern: arg : match any, but also bind args to lambda during pattern declaration.
      • Wildcard: _ : match any, but move values from arg to the lambda.
      • Identifier: work by names, matching by comparing with pattern name.
      • Destructure: ds(<pattern>,...) it's like matching a tuple by structured binding.
      • Optional: some(<pattern>) | none : to match optional or pointer, any of which can be deref.
      • As: as<typename>(<pattern>) : this could mainly be used to match the typename itself.
      • Visit: vis(<pattern>)
      • Alternation: anyof(<pattern>)
      • Variadic: variadic(<pattern>) : which can only be used along with the variadic lambda.
    • Reason: more expressive code, not necessary faster though.
      • Some clauses to help on match:
        • WHEN(boolean expression) will help better on negating unwanted match(es).
      • Pattern statements:
        • if_let match one pattern, other execution paths left uncalculated.
        • for_let match one pattern, and loop over ranges.
