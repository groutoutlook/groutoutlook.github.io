    • Resolution:
      • Hierarchical sheet pins
      • Recite: Electrical connections between sheets are made with labels. There are several kinds of labels in KiCad, each with a different connection scope.
        • l == Local labels only make connections within a sheet. Therefore local labels cannot be used to connect between sheets.
          • this is the one which looks like a reference hover over the line. you need to click on wire to assign things to net.
        • ctrl+l == Global labels make connections anywhere in a schematic, regardless of sheet. can be used to make connections between sheets whether the sheets are top-level or hierarchical.
        • h == Hierarchical labels in subsheet connect to hierarchical sheet pins accessible in parent sheet. Hierarchical designs rely on hierarchical labels and pins to connect between parent and child sheets. Think of sheet pins as defining the interface for a subsheet; hierarchical labels within the child sheet connect to corresponding sheet pins which are visible in the parent sheet.
