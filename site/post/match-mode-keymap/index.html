  • Match mode - Keymap
    • Recap:
    • Run: mim/mam is the most common I used.
    • Resolution: match mode can be used with normal / select / extend mode.
      • ms[ add surround [, map it to S.hard to remember ms things... surround_add
        • S is split_selection, as s is select_regex, this can spawn new cursor on certain chars/words.
      • mr[* replace surround [ with surround * e.g. parenthesis to brace. notice selection should not include surrounds at all, or it will not work.
        • mr[ motion dont need to pre-select. Specify pair and helix do the rest.
      • md[ delete surround [. It deletes virtually any char you put after, even md<space> work.
    • Reason:
      • Those actions are actually more useful while using phones than desktop.
      • (: rotate main selection backward rotate_selections_backward
      • ): rotate main selection forward rotate_selections_forward
      • Alt-(: rotate selection contents backward rotate_selection_contents_backward`
      • Alt-): rotate selection contents forward rotate_selection_contents_forward`
    • Root: the most significant difference compared to vim.
    • Related:
      • Movement
        • f,F,t,T is not limit by the current line.
        • . : repeat_last_insert, which you enter insert mode, type and enter multicursor mode.
          • either v/ or C/S... and press .. will repeat insert but in the end of line.
        • Alt+. : repeat_last_motion, mapped to ,, map in normal and selection mode.
          • Use repeat_last_motion to jump as flit.nvim does.
            • Repeat last motion of those f, t, m, [, ].
      • d originally delete_selection, map to delete_selection_noyank.

      • K/Shift+k further selection while in multiple cursors. keep_selection, whitelist style.
        • For example, try spawn multiple cursor then x/X or expand.
          • Then K and type a phrase within those selection ranges.
