$files = (gci *webm,*mkv -exclude "-reenc"); $files| % { # prevent recurring reencode...
    $file = $_.BaseName;
    ffmpeg -i ".\$($_.Name)"  -map 0:v -c:v copy -map 0:a -c:a copy -map 0:a -strict -2 -c:a aac ".\$file-reenc.mkv"

      • search/searchplay [ ]... Searches for substrings in song tags. (and play). Any number of tag type and query combinations can be specified. tag: artist, album, title, track, name, genre, date, composer, performer, comment, disc, filename, or any (to match any tag).
      • find/findadd [ ]... == search but tag values must match query exactly instead of doing a substring match.
      • add if you do add / it will add everything in database.
