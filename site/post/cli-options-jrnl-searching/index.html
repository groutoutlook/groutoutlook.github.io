  • CLI Options - jrnl - Searching
    • Recap:
    • Run: 
      jrnl --list # all configured journals.
jrnl cli -c "jrnl" --edit #-contains is actually abbreviate-able to `-c`
j cli -c "jrnl" -and -c "searching" #default is "OR" logic.
j cli -c "jrnl" 2e # even this is possible.
j cli -c jrnl --format json # output json, even xml or yaml with this.
    • Root:
    • Resolution: Replace all paths to symlinks.
      • --import If any entries have the exact same content and timestamp, they will be deduplicated.
        • Use with --file FILENAME. If not provided FILENAME, jrnl will use STDIN.
          • Which means you can pipe to it.
      • --change-time DATE Interactively changes the time of the selected entries to the date specified, or to right now if no date is specified. You'll be asked to confirm each entry, unless you are using this with --edit on a single entry.
