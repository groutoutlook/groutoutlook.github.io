  • input.conf syntax
    • Recap: while single-key bindings override builtin bindings, it's not for multi-key sequences. For example, b-c sequence in input.conf would be overridden by builtin binding b. In this case, if you don't care about b, you can b ignore.
      • bind both b and a-b-c won't work, since b would override a-b-c
        • add a-b ignore would allow that, longest match a-b is ignored, and following c would trigger the sequence a-b-c while b alone would still work.
    • Run: 
      mpv --input-keylist # list all keybindings.
      • load-input-conf <filename> Load an input configuration file, similar to --input-conf option. If the file was already included, its previous bindings are not reset before it is reparsed.
