  • termframe output/stdout capturing SVG Terminal screenshot
    • Recap: #nightly this one. I shim termshot to this as well. Terminal shoot, screenshot or so.
      • to compile this one, not only full rust but gcc in #windows as well. I got it from scoop.
    • Run: 
      bat "$(zqi nightly termframe)\assets\test\input\sample.ansi" | termframe > ./ansi.svg && msedge file://$pwd/ansi.svg
tree --color=always *>&1 | termframe > tree-l1.svg && msedge file://$pwd/tree-l1.svg # `eza` trim color in pipe by default.
r l *>&1 | termframe > ./just-lint.svg
      • #browser #til msedge and chrome are picky about path, has to be a URI with file:// URI scheme.
      • termframe always capture ANSI color,
        • if you dont see it try to find the cli option to toggle it in pipeline. or some PowerShell default.
    • Resolution:
      • Recite: Use auto-sizing to determine optimal dimensions based on command output. 
        # Auto-detect both width and height
termframe --width auto --height auto -o output.svg -- command

# Width between 80 and 120 columns, height auto-detected
termframe -W 80..120 -H auto -o output.svg -- command

# Width between 80 and 200 columns, step of 4, initial 120
# Height auto-detected, initial 40
termframe -W 80..200:4@120 -H @40 -o output.svg -- command
    • Reason: for troubleshoot/reporting issues to code authors. Even peers.
