  • Schematic Editor | Update Schematic from PCB (back annotation)
    • Recap: it's reversed from the default keybinding eeschema -> pcbnew by F8
    • Run: Tools -> Update Schematic from PCB... I map it to shift+f8
      • very useful if you want to assign net using pcbnew first due to pin issues, backport to eeschema.
    • Resolution: can mark "Do not populate" in component settings so you can d on 3d viewer to not see it in renderer. It will cross out and grayed the component in eeschema.
      • If you want it to not be updated into pcbnew, mark all "Exclude from board", "Exclude from BOM", "Exclude from position files".
      • In component's footprint properties in pcbnew, it's also possible to toggle "Do not populate".
