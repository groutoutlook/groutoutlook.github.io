  • The mouse input of the two finger and the three finger inputs both have pro and cons
  • Right click is handled by holding the position, 500ms or so. It's more like a touch screen now, from Chrome Remote Desktop interface.
    • Which is, it's not handled by other application by a normal right click.
  • Two finger is better at simulating the middle scroll using one finger, use one finger to swipe, swipe.
    • Cons is, zooming is now 2 finger only, zoom the whole screen, looks like zoomit in #sysinternal or the default tool of windows, magnify.
      • Which means, cant send zoom action in applications.

  • Three finger make swipes using 2 finger, zoom all screen using 3 fingers.
