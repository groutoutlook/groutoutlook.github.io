  • Set-PSBreakpoint | sbp
    • Recap: invoke breakpoint inside REPL.
    • Run: Can run in psm1 as well as ps1. 
      sbp -s "$((gmo quickPwshUtils).Path)" -Line 242 # REPL debugging with powershell.
      • Or can run in function/cmdlets by name/alias. -Commmand can not be used with -Line.
      sbp -c "rvcb"
      • Debugging Advanced Functions (with begin,process,end) It will break on each of start on those 3 blocks. Otherwise, it's breaking on start only.
      • about_Debuggers | Debugger commands
        • When you hit Breakpoints in REPL. it will prompt you that you have enter debug mode. Use this as gdb, quite funny to see that.
          • Keybinding(?)/Command: ? to see all help. only care about s/v/c. o step out. l show contexts. k show call stacks.
    • Resolution:
      • breakpoint on a variable
        • breakpoint on every command that begins with specified text, by glob.
        • breakpoint depending on the value of a variable/data breakpoint in powershell
      • debugger environment - $PSDebugContext
    • Root: Stepping through PowerShell Scripts with the PowerShell Terminal
    • Reason: I need a data breakpoint in powershell, within #ide/vscode.
