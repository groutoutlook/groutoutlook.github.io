  • ISP: In-system programming
    • Recap: also called in-circuit serial programming, is the ability of some programmable logic devices, microcontrollers, chipsets and other embedded devices to be programmed while installed in a complete system.
      • rather than requiring the chip to be programmed prior to installing it into the system.
      • Which is practically the act of reburning the chips...
      • BOOT0, BOOT1 is the result of ISP, which you have a bootloader to program the other part.
    • Resolution: ICP : In Circuit Programming which utilize JTAG or SWD interface
      • IAP: In Application Programming, burn program on runtime, use UART, I2C, SPI and many other which is set up in runtime.
