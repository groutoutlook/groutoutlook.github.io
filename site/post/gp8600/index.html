      • Recite: This is a PAC/DAC chip that outputs voltage and current on the same port, capable of 0-5V/0-6V/0-10V/0-12V/0-20mA/4-20mA outputs. Designed for cost-effective applications, it features a recommended 15V supply voltage. It features a built-in high-performance, low-drift reference, a 16-bit DAC, and 0.03% linearity. It's packaged in the ESOIC-10 (similar to the SOIC-8) package. In PAC mode, voltage and current are switched using the MSEL and RSEL strobes; in DAC mode, they're switched using I2C commands .
