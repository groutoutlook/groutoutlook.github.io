  • filter in function
    • Recap: (Prefix) a type of function that runs on each object in the pipeline.
      • A filter resembles a function with all its statements in a process block.
    • Run: 
      function Add-One { process { 1 + $_ } }
filter Add-Two { 2 + $_ }
3 | add-one | add-two
    • Resolution:
    • Reason: Quick to write a pipeline function which use the $_ auto var.
      • Pro: short
      • Con: not an usual use. get familiar with function ... process instead. They also get you a $_ to use.
