    • Brief:
    • Origin: Trying to grep files name with matched line number only, from ripgrep.
    • Resolution: Instead of using $1 as matching results, we have to use "`$1" to indicating matches.
      • Since the $ symbol is the alias with variable expansion in PowerShell as well.
      • Something like:
      (rg "fake" -n -g !"*.js") -replace ":(\d+):.*",":`$1"
      • The above solution is for double quotes. Related links describe usage with single quotes, which is easier, no backtick involved.
