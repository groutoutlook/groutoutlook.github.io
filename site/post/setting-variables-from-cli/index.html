    • Reason: positional arguments may also be turned on on a per-recipe basis...
      • with the [positional-arguments] attribute.
        • note that powershell does not handle positional arguments in the same way as other shells, so turning on positional arguments will likely break recipes that use powershell.
          • the -commandwithargs flag will make positional arguments work as expected.
            • not work for current v7.6 preview.
          set shell := ['pwsh.exe', '-commandwithargs']
