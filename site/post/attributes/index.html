    • script recipes
      • [script(command)] attribute are run as scripts interpreted by command.
        • recipes with an empty [script] attribute are executed with the value of
          • set script-interpreter := […], defaulting to sh -eu.
        • the body of the recipe is evaluated, written to disk in the temporary directory, and run by passing its path as an argument to command.
        • the [script(…)] attribute is unstable, so you'll need to use set unstable, set the just_unstable environment variable, or pass --unstable on the command line.
    • [[doc] attribute can be used to set or suppress a recipe's doc comment.
      • just --usage should support multi-line documentation comments by [doc] attribute
    • concatenated string in custom script() attributes
      • use with nix-shell and python for example.
