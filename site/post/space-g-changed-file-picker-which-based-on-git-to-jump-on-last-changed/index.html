    • Resolution:

      • #config set Ctrl+, to config-open which means #windows/terminal is set to Ctrl+alt+,

    • Reason:

      • goto_word does save_selection to jumplist before making the jump

    • Recite: | Keybinding | Action | Command | | ---------- | ------------------------------------------ | ---------------- | | Ctrl+i | Jump forward on the jumplist | jump_forward | | Ctrl+o | Jump backward on the jumplist | jump_backward | | Ctrl+s | Save the current selection to the jumplist | save_selection |
