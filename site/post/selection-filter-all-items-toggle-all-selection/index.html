  • Selection filter -> All items toggle all selection.
    • Recap: so you can select all tracks with a mouse selection without fear, quicker.
    • Resolution: Right click on a filter will show a menu "only pad" for example.
      • This helps copy a pad and throw around easily. Without adding them first to eeschema.
        • Can delete/change nets. Although you have to e the pad itself, not the footprint.
      • #keybinding #config Alt+shift+f == Filter Selected Items based on items type among selections.
        • So you could leave selection filter there, and press this to fine-grain results.
        • It's having CUA's Alt+letters inside for quicker toggling.
