  • Component placement (.pos) need to have correct origin, if not you have to offset it from the top left of the board.
    • Recap: AD is quite lenient about that, for KiCad, you have to move the board all the way up to the top left drawing position.
    • Run:
      • PCB position file export, .pos, .ptl something
        • Plain text or ASCII, those are what make me suffer while doing work with AT32_25
      kicad-cli pcb export pos .\FT32_F6C_26.kicad_pcb -o .\FT32_F6C_26-prod\FT32_F6C_26.pos
